# Job Application Tracker

A simple command-line app to track job applications. Built with Python and SQLite.

## Features
- Add a job with company, role, and deadline
- List all saved applications
- Update the status (Applied, Interview, Selected, Rejected)

## How to run
1. Make sure Python 3 is installed.
2. Download `job_tracker.py`.
3. Run `python job_tracker.py` in a terminal.

Data is saved in a local `jobs.db` file created automatically on first run.

## Built with
- Python 3
- SQLite (sqlite3 module)
